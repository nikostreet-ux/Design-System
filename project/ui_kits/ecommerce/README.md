# UI kit — rosen.cl (e-commerce B2C)

Recreación de las vistas centrales de la tienda online de Rosen, construida **solo** a partir del Manual de Marca entregado (colores, tipografía Inter, reglas de logotipo) y del contexto de negocio. No se entregó código ni Figma del sitio real, por lo que la maquetación es una interpretación fiel de las fundaciones del sistema, **no** una réplica pixel-perfect de rosen.cl.

## Pantallas
| Archivo | Vista |
|---|---|
| `Chrome.jsx` | Barra de anuncio, header con buscador, navegación de categorías, footer |
| `Home.jsx` | Hero full-bleed, categorías, destacados, franja de servicios |
| `Catalog.jsx` | Listado con filtros laterales, chips activos, orden y grilla de 3 |
| `Product.jsx` | Galería, selector de medida, precio, pestañas de ficha |
| `Cart.jsx` | Carro con resumen y despacho |

## Imágenes
El manual no incluye fotografía. Todos los espacios de imagen son placeholders etiquetados con su formato (4:3, 1:1, 21:9) para que el equipo de marca los reemplace.

Abrir `index.html` — la navegación entre las cuatro vistas es funcional.
