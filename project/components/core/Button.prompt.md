Botón principal de Rosen — úsalo para toda acción (CTA de ficha de producto, formularios, filtros aplicados).

```jsx
<Button variant="primary" size="lg">Agregar al carro</Button>
<Button variant="accent">Comprar ahora</Button>
<Button variant="secondary" size="sm">Ver detalle</Button>
```

Variantes: `primary` (relleno #38484E, por defecto), `accent` (Rojo Rosen — máximo un botón rojo por vista), `secondary` (contorno slate), `ghost` (contorno gris), `inverse` (blanco sobre fondos oscuros/imagen), `link` (texto con subrayado fino). Tamaños sm 36 / md 46 / lg 56 px de alto. El label va siempre en mayúsculas.
