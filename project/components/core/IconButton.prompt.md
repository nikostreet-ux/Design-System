Acción de un solo icono, siempre con `label` accesible.

```jsx
<IconButton label="Buscar" variant="ghost"><Icon name="search" /></IconButton>
<IconButton label="Cerrar" variant="outline" size="sm"><Icon name="x" /></IconButton>
```

Variantes: ghost (header y toolbars), outline, solid, inverse (sobre imagen o fondo slate).
