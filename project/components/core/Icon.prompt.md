Wrapper de iconos Lucide con trazo 1.5 — el único set de iconos del sistema (sustitución documentada: el manual de marca no define iconografía propia).

```jsx
<Icon name="shopping-cart" size={20} />
<Icon name="chevron-right" size={16} strokeWidth={1.25} />
```

Hereda `currentColor`, así que toma el color del botón o texto contenedor. Nunca uses emoji ni caracteres unicode como iconos.
